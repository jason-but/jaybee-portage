## Instructions to push to GIT

Some basic instructions to myself for pushing updates

### Editing existing files

```bash
git commit -m "new comment"
git push -u origin main
```

### Adding new files/folders

```bash
git add <filename>
git add <folder>
git commit -m "new commit"
git push -u origin main
```
